# animego downloader

Работа с видео с [animego.me](https://animego.me) — три инструмента:

- **Chrome-расширение** ([chrome-extension/](chrome-extension/)) — кнопка на странице
  аниме, панель с выбором плеера/озвучки/серий, скачивание средствами браузера.
  Без серверной части.
- **CLI-скрипт** ([animego_downloader.py](animego_downloader.py)) — то же самое
  из командной строки.
- **Userscript для iPhone** ([ios-userscript/](ios-userscript/)) — кнопка на странице
  аниме в Safari, отправляет серию в приложение AniLabX на телевизоре (протокол
  XRemote). Без компьютера: через «Быстрые команды» и a-Shell.

Оба построены по гайду [«Разбор плееров аниме-сайтов» (Habr)](https://habr.com/ru/articles/1079156/)
и его библиотеке [anime-dl-core](https://github.com/ialakey/anime-dl-core) — её логика
для CVH и Kodik портирована в `chrome-extension/extractors.js`.

Инструменты читают только то, что отдаёт обычный браузерный плеер: DRM и платные
ограничения не обходятся. Для личного использования.

---

## Chrome-расширение

### Установка

1. `chrome://extensions` → включите «Режим разработчика» (переключатель справа сверху)
2. «Загрузить распакованное расширение» → выберите папку `chrome-extension` проекта
3. Папку `chrome-extension` после установки не перемещать и не удалять —
   Chrome грузит код расширения из неё

### Использование

1. Откройте страницу любого аниме на animego.me — справа внизу появится
   фиолетовая кнопка со стрелкой.
2. Кликните — раскроется панель:
   - **Плеер** — CVH (mp4 144p–1080p, рекомендуется) или Kodik (mp4 360p–720p).
     Озвучки на разных плеерах различаются: если нужной нет в одном —
     переключите другой, список озвучек перестроится.
   - **Озвучка** — доступна для выбранного плеера.
   - **Качество ≤** — скачается ближайшее доступное не выше выбранного.
   - **Серии** — чипы, кнопка «все».
3. «Скачать выбранные» — серии уйдут в загрузки браузера
   (`Загрузки/<подпапка>/Название - эпизод N [Озвучка][720p].mp4`).

Значения по умолчанию (плеер, качество, подпапка) задаются в настройках:
иконка расширения в тулбаре или `chrome://extensions` → AnimeGO Downloader → «Настройки».

### Как оно работает (без сервера)

```
страница аниме (content script)
  └─ background service worker:
       GET animego.me/player/{id}/episodes        → список эпизодов
       GET animego.me/player/videos/{episodeId}   → embed-ссылки CVH/Kodik по озвучкам
       CVH:  plapi.cdnvideohub.com playlist/video → прямые mp4
       Kodik: страница + POST /ftor → base64+цезарь → прямые mp4
       chrome.downloads.download()                → загрузка браузером
```

- Cross-origin запросы разрешает `host_permissions`, CORS не мешает.
- Прямые mp4 CDN работают с обычным UA браузера (CVH проверяет именно его).
- Referer для API CVH ставит session-rule `declarativeNetRequest` —
  service worker не может указать Referer в fetch сам.
- Kodik работает вовсе без Referer/Origin (проверено), подписи одноразовые,
  поэтому между сериями пауза 1.5 с.

## CLI-скрипт

```bash
pip install -r requirements.txt

python animego_downloader.py URL --list                          # озвучки и серии
python animego_downloader.py URL --episode 1-3,7 --dub "Dream Cast" --quality 1080
python animego_downloader.py URL --episode all                   # всё
python animego_downloader.py URL --episode 1 --show-streams      # только ссылки
```

Активный плеер задаётся множеством `ENABLED_PROVIDERS` в начале скрипта
(сейчас только `cvh`; kodik/aniboom за заглушкой, код сохранён).
ffmpeg нужен только для HLS; если его нет в PATH, используется бинарник
из пакета `imageio-ffmpeg`.

## Userscript для iPhone: трансляция в AniLabX

Открывает серию с animego.me в приложении [AniLabX](https://github.com/AniLabX)
на телевизоре по его протоколу XRemote — без компьютера. Ничего не скачивает:
на AniLabX уходит только ссылка, он качает её сам.

AniLabX принимает команду XRemote только по «голому» TCP-сокету, а из Safari можно
отправить лишь http-запрос. Поэтому сообщение идёт в два шага: userscript собирает
его и передаёт быстрой команде «Команд», а та выполняет в a-Shell (его `nc` умеет
открывать сокет):

```
страница аниме (userscript в Safari)
  └─ GET animego.me/player/{id}/episodes        → список серий
     GET animego.me/player/videos/{episodeId}   → embed-ссылки CVH/Kodik по озвучкам
     CVH:  plapi.cdnvideohub.com playlist/video → прямые mp4
     Kodik: страница + POST → base64+цезарь     → прямые mp4
     сообщение XRemote (PLAY_VIDEO) → команда echo <hex> | xxd -r -p | nc <ip> <port>
       └─ shortcuts://run-shortcut → «Быстрые команды» выполняет её в a-Shell
                                              → AniLabX играет
```

### Установка (один раз)

1. Из App Store установите **Userscripts** (запускает userscript в Safari) и
   **a-Shell** (терминал, из него открывается сокет до AniLabX).
2. Положите `ios-userscript/animego-xremote.user.js` в папку Userscripts
   (она видна в «Файлах» → «На iPhone» → Userscripts). Перекинуть файл на телефон
   можно через iCloud; либо открыть на телефоне ссылку на файл, положенный на
   любой http-сервер (например `python -m http.server` в папке проекта), и
   сохранить его в эту папку.
3. Включите расширение: Настройки → Приложения → Safari → Расширения →
   Userscripts → разрешите. Доступ к сайтам — «Разрешить на всех веб-сайтах»:
   запросы к CVH и Kodik идут от имени расширения.
4. Откройте a-Shell и проверьте связь с телевизором (заодно iOS спросит разрешение
   на локальную сеть — ответьте «OK»):
   ```
   echo '{"API_VERSION":10,"COMMAND":"PING"}' | nc -w 3 192.168.1.140 31337
   ```
   Должно напечатать `{"API_VERSION":10,"RESPONSE":"ALIVE"}` — XRemote-сервер
   в AniLabX должен быть запущен.
5. Создайте быструю команду с именем **XRemote**. Она просто выполняет то, что
   присылает userscript, поэтому IP и порт сервера задаются не в ней, а в настройках
   панели (⚙) и хранятся в userscript.
   - действие **Match Text** (поиск по регулярному выражению): искать в «Входных
     данных быстрой команды» выражение
     `^echo [0-9a-f]+ \| xxd -r -p \| nc -w [0-9]+ [0-9]{1,3}(\.[0-9]{1,3}){3} [0-9]{1,5}$`;
   - действие **Если** («Совпавший текст» имеет любое значение), внутри него —
     **a-Shell → Execute Command**, где поле команды — переменная «Входные данные
     быстрой команды», а `Open the app to execute the commands?` — «default»
     (команда выполнится в фоне, не сворачивая Safari); здесь же по желанию —
     «Показать уведомление» с результатом `output`, чтобы видеть ответ AniLabX;
   - в ветке «Иначе» — «Показать уведомление», например «XRemote: отклонено».

   Проверка нужна потому, что без неё команда выполнит любой присланный текст,
   а вызвать её может любая страница в Safari. Регулярное выражение пропускает
   только наш формат.

### Использование

Откройте страницу аниме на animego.me, нажмите фиолетовую кнопку с значком
трансляции, выберите плеер, озвучку и качество и нажмите на серию. Safari спросит,
открывать ли «Быстрые команды», — ответьте «Открыть», и серия запустится в AniLabX
(CVH — через пару секунд, Kodik — через 5–8, он дольше стартует).

Адрес сервера (IP и порт) и имя быстрой команды задаются в настройках панели (⚙).
Кнопка «Проверить связь» там же отправляет тестовый запрос тем же путём.

Подтверждение Safari появляется при каждой отправке — обойти его нельзя.
Пульта нет: остановить воспроизведение можно кнопкой в панели, остальное —
пультом телевизора.

### Если не работает

- **Панели на странице нет** — расширение Userscripts не включено или ему не разрешён
  сайт animego.me.
- **«запрос к … заблокирован»** — разрешите Userscripts доступ ко всем сайтам (шаг 3).
- **Safari не спрашивает про «Быстрые команды»** — команды с именем из настроек
  панели (⚙) не существует.
- **Серия не запускается, хотя вопрос Safari появился** — проверьте адрес сервера в
  настройках панели (⚙) и связь вручную (шаг 4): нет `ALIVE` — значит, XRemote-сервер
  в AniLabX не запущен или адрес неверен.
- **«XRemote: отклонено»** — userscript и проверка в быстрой команде не согласованы:
  сверите регулярное выражение (шаг 5) и обновите userscript.

### Особенности

- Ссылки CVH привязаны к типу клиента, который их запросил: CDN отдаёт файл только
  ему, и лишь несколько раз. Скрипт запрашивает их как Chrome (плеер AniLabX ходит
  так же); если Safari не даёт подменить User-Agent, ссылка остаётся «сафари», и
  плееру передаётся User-Agent телефона — AniLabX это учитывает.
- Поле `SEASON` в сообщении обязательно: без него сервер AniLabX падает.
  Для Kodik сезон из ссылки не узнать, поэтому ставится «1 сезон».
- Код извлечения ссылок — копия `chrome-extension/extractors.js`; при правке там
  править и здесь.

## Тесты

```bash
node test_extractors.mjs                    # живые сети: цепочка animego + CVH + Kodik
node test_background_sim.cjs                # реальный background.js с заглушками chrome.*
node ios-userscript/test_userscript.mjs     # userscript против настоящих animego/CVH/Kodik
node ios-userscript/test_userscript.mjs --live   # то же сообщение настоящему серверу
                                                 # XRemote — запустит видео на телевизоре
```

UI-панель можно проверять без установки расширения: `python -m http.server 8791`
в корне проекта и открыть `http://127.0.0.1:8791/ui-test/test.html` — страница
подключает реальные `content.js`/`content.css` со стабами `chrome.*`. Панель
userscript — там же, `http://127.0.0.1:8791/ios-userscript/ui-test.html` (стабы
сети и `GM.*`).

## Заметки

- Прямые ссылки подписанные и живут минуты, кэшировать бессмысленно —
  они получаются заново перед каждым скачиванием (и могут быть привязаны к IP).
- Разметка `data-*` на animego периодически меняется; при поломке первым делом
  проверяйте регулярки (`fetchEpisodes`/`fetchProviders` в background.js и класс
  `AnimeGo` в python-скрипте).
