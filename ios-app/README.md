# AnimeGO Cast (iOS)

Приложение для iPhone с Share Extension: в Safari на странице тайтла animego.me
нажмите «Поделиться» → «AnimeGO Cast», выберите серию — она запустится в AniLabX
на телевизоре. Ничего не скачивается: на телевизор уходит только прямая ссылка,
AniLabX качает и играет сам. Поддерживаются плееры CVH (до 1080p) и Kodik (до 720p).

Требуется iOS 17+. Код — Swift/SwiftUI, без сторонних библиотек; проект генерируется
XcodeGen'ом, сборка идёт в GitHub Actions (неподписанный IPA), подпись и установка
на телефон — через Sideloadly на Windows.

## Сборка (GitHub Actions)

1. Откройте страницу Actions репозитория
   (`https://github.com/Mon4ik-hub/xremote_ios/actions`), выберите workflow **ios**
   и последний запуск — либо запустите новый кнопкой **Run workflow**.
2. Дождитесь зелёного статуса. Шаги прогона: `xcodegen generate` → `xcodebuild test`
   (тесты XCTest на симуляторе iPhone) → сборка неподписанного архива → упаковка IPA.
3. Внизу страницы запуска, в разделе **Artifacts**, скачайте **AnimeGOCast-unsigned**:
   внутри `AnimeGOCast-unsigned.ipa` и вывод тестов. Сертификаты не нужны —
   IPA подписывается локально на шаге установки.

## Установка через Sideloadly (Windows)

1. Установите iTunes **с сайта Apple** (версия из Microsoft Store не ставит
   нужные USB-драйверы): apple.com/itunes/download/win64.
2. Установите [Sideloadly](https://sideloadly.io/).
3. Подключите iPhone кабелем, разблокируйте и подтвердите доверие компьютеру.
4. Перетащите `AnimeGOCast-unsigned.ipa` в окно Sideloadly, введите свой Apple ID
   и нажмите **Start** — подпись ставится и на приложение, и на расширение.
5. На телефоне: **Настройки → Основные → VPN и управление устройствами** →
   выберите свой Apple ID → **Доверять**.

С бесплатным Apple ID подпись живёт **7 дней** и действует не больше чем на
**3 приложения** (лимиты Apple). Продление — повторная установка через Sideloadly.

## Как включить расширение

1. В Safari откройте страницу тайтла на animego.me.
2. Кнопка **Поделиться** → в списке выберите **AnimeGO Cast**. Если пункта нет —
   прокрутите список до конца → **Изменить действия** → добавьте AnimeGO Cast.
3. Откроется панель: название тайтла, доступные плееры и озвучки, список серий.
   Нажмите на серию — она запустится на телевизоре; внизу появится одна строка
   результата: «Запущено на «Телевизор»: эпизод 5, 1080p» либо причина ошибки.

## Профили телевизоров

По умолчанию один профиль «Телевизор» — `192.168.1.140:31337`. Профили настраиваются
в самой панели (кнопка **Профили**):

- **Добавить телевизор** — имя, IP/хост, порт. Кнопка **Проверить** отправляет PING
  именно этому адресу и показывает ответ тут же.
- Нажатие на профиль — редактирование; свайп по строке — удаление
  (единственный профиль удалить нельзя).
- Телевизор, на который отправляли последним, стоит в списке первым.
- Отправка серии: при одном профиле — сразу; при нескольких — сначала список
  телевизоров, нажатие отправляет серию на выбранный.

## История (продолжить без Safari)

iOS не даёт расширению молча открыть приложение после отправки, поэтому запись
в историю — по кнопке. После запуска серии в панели появляется кнопка
**«Записать в историю приложения»**: нажмите — откроется приложение, тайтл и серия
попадут в **«Историю»**. Дальше продолжать можно прямо из приложения: тайтл →
список серий грузит само приложение → серия запускается на телевизоре
(плеер, озвучка и телевизор подставляются из отправки). Свайп по строке серии
помечает просмотренное; свайп по записи истории удаляет её. Если телевизоров
несколько, при отправке из приложения откроется выбор.

## Плеер и озвучка

В панели расширения секция «Настройки»: **Плеер** (CVH или Kodik, выбор запоминается)
и **Озвучка** — список зависит от выбранного плеера. Отправка идёт выбранным плеером:
если выбранной озвучки в какой-то серии нет, автоматически пробуются остальные
озвучки того же плеера; плеер сам не подменяется — при неудаче подсказывается,
какой плеер стоит выбрать.

**Просмотренные серии**: после успешной отправки серия помечается зелёной галочкой.
Свайп по строке серии ставит или снимает пометку вручную.

## Если не работает

- **Доступ к локальной сети**: при первой отправке или проверке связи iOS спросит
  разрешение — ответьте «Разрешить». Если отказали: **Настройки → Приватность и
  безопасность → Локальная сеть** → включите AnimeGO Cast.
- **«Сервер не ответил за 5 секунд»**: телефон и телевизор должны быть в одной
  Wi-Fi-сети, на телевизоре должен быть запущен AniLabX (его XRemote-сервер).
  Проверьте адрес кнопкой **Проверить** в профиле.
- **«CVH: плейлист пуст …»**: у части тайтлов CVH регионально заблокирован
  (в браузере над плеером висит «Контент запрещен на территории РФ»). Переключите
  плеер на Kodik в «Настройках» панели — для таких тайтлов он обычно доступен.
- **COMMAND_FAIL / EXCEPTION**: AniLabX отверг команду — попробуйте другую
  озвучку/плеер (переподелитесь страницей заново: ссылки короткоживущие и
  запрашиваются только в момент отправки).
- **Пункт расширения пропал**: перезапустите Safari; если не помогло —
  переподпишите IPA через Sideloadly и заново доверьте разработчика.

## Структура и разработка

- `project.yml` — описание проекта для XcodeGen (сборка: `xcodegen generate`).
- `App/` — контейнерное приложение (экран-инструкция, логики не содержит).
- `ShareExtension/` — вся логика: точка входа, экраны SwiftUI, вью-модель.
- `Core/` — общий код обоих таргетов: `AnimeGoClient` (цепочка animego),
  `CvhExtractor`/`KodikExtractor` (прямые ссылки), `CastMessage` (сообщения
  XRemote), `XRemoteClient` («голый» TCP, таймаут 5 c), `TvProfiles` (профили
  телевизоров в UserDefaults расширения).
- `Tests/` — XCTest: разбор HTML, декод ссылок Kodik, выбор потока, сборка
  сообщения, XRemote против mock-сервера (NWListener), хранилище профилей.
  Запускаются в CI на симуляторе iPhone.

Стиль проверяется SwiftLint'ом (конфиг `.swiftlint.yml`):
`swiftlint lint ios-app --quiet --disable-sourcekit`.
